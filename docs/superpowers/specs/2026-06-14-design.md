# Design Spec — Immobilien Portfolio Manager

**Datum:** 2026-06-14 (aktualisiert 2026-06-16)
**Status:** Aktualisiert — neues visuelles System

---

## Designrichtung

Light Mode only. Kein Dark Mode. Modern, clean, iOS-nativ mit blauen Akzenten und leichtem Glassmorphism. Visuelle Hierarchie durch Typografie und Farbe (Blau für Struktur, Rot/Grün für Werte).

---

## Visuelles System (Light Mode)

### Hintergrund

```
App-Hintergrund: linear-gradient(145deg, #dce8f8 0%, #e8f0fb 100%)
```

Hellblauer Gradient — gibt dem gesamten Interface eine ruhige, konsequente Grundstimmung.

### Karten (Glass Cards)

```swift
background: rgba(255,255,255,0.80)
backdropFilter: blur(24px)
border: 1px solid rgba(255,255,255,0.95)
borderRadius: 18px
boxShadow: 0 4px 16px rgba(0,0,0,0.06)
```

Alle Content-Karten als frosted-glass — weiß mit leichter Transparenz und Blur auf den Hintergrund.

### Section-Labels (Abschnittsüberschriften innerhalb Karten)

```
Farbe:       #1d4ed8 (Blau)
Schrift:     11px, font-weight 700, uppercase, letter-spacing 0.5px
```

Beispiel: "STEUERLICHES ERGEBNIS", "CASHFLOW", "ZUSAMMENFASSUNG"

### Abschnittstrennlinie (innerhalb einer Karte)

```css
height: 1.5px;
background: linear-gradient(90deg, rgba(59,130,246,0.35), transparent);
border-radius: 2px;
```

Blauer Gradient-Strich trennt zwei Sektionen innerhalb einer Karte (z.B. Steuerliches Ergebnis von Cashflow).

### Badges / Status-Tags

```
Ist:         Vollblau  #3b82f6, weißer Text, border-radius 6px
Prognose:    Outline   border #3b82f6, blauer Text
Status-Tags: farbig je Status (grün, lila, orange, etc.)
```

### Ergebnis-Werte (große Zahlen)

```
font-size: 18px, font-weight: 800, letter-spacing: -0.5px
Positiv:  #15803d (dunkelgrün)
Negativ:  #dc2626 (rot)
```

### Zeilenwerte (Tabellen, Listen)

```
Label:  12px, color #475569 (gedimmtes Blaugrau)
Wert:   12px, font-weight 600, tabular-nums
Negativ: #dc2626
Positiv: #059669
Neutral: #0f172a
```

## Typografie

Systemschrift SF Pro. Zahlen immer in SF Mono (tabular-nums, untereinander ausgerichtet).

| Rolle | Größe | Gewicht | Verwendung |
|---|---|---|---|
| Tab-Titel | 17–22px | 700 | "Cashflow", "Steuer" |
| Section-Label | 11px | 700, uppercase | "STEUERLICHES ERGEBNIS" |
| Ergebnis-Zahl | 18–22px | 800 | Cashflow nach Steuer, Steuereffekt |
| Zeilen-Label | 12px | 500 | "Einnahmen", "Zinsen" |
| Zeilen-Wert | 12px | 600 | Beträge |
| Caption | 10px | 700, uppercase | Spaltenheader in Tabellen |

---

## Spacing

- Card-Padding: 16px horizontal, 6px vertikal (Zeilen)
- Zeilen-Padding: 8–10px vertikal
- Gap zwischen Karten: 10–12px
- Section-Label Abstand oben: 10–12px

---

## Navigation & Layout

Schmale Sidebar links, breiter Content-Bereich rechts.

```
Tab-Leiste Immobilien-Detail: Übersicht | Cashflow | Steuer | Finanzierung | Einstellungen
```

---

## Icons

SF Symbols — keine eigenen Icons.

---

## Tabellen

- Keine Zebra-Stripes (kein abwechselnder Hintergrund je Zeile)
- Zahlenkolumnen rechtsbündig, SF Mono
- Status-abhängige Zeilen: kein Sonder-Hintergrund (nur Wert-Farbe signalisiert Bedeutung)
- Trennlinien: 1px `rgba(0,0,0,0.04–0.06)`

---

## Animationen

Subtile Übergänge — max. 200ms. Kein Übertreiben.
