# Design Spec — Immobilien Portfolio Manager

**Datum:** 2026-06-14
**Status:** Abgeschlossen

---

## Designrichtung

Eigenständig und modern — nicht nativ macOS. Klare visuelle Hierarchie durch Typografie statt Farbe. KPI-Karten mittelgroß, gut gruppiert. Farbe nur gezielt für Status und Werte. Funktioniert gleichwertig in Light und Dark Mode.

---

## Farbe & Kontraste

**Akzentfarbe**
- Blau `#2563EB` — aktive Navigation, Buttons, Links. Nur wo der Nutzer etwas tun kann.

**Statusfarben** — ausschließlich für Werte und KPI-Bewertungen

| Bedeutung | Farbe | Hex |
|---|---|---|
| Positiv / gut | Grün | `#16A34A` |
| Negativ / schlecht | Rot | `#DC2626` |
| Neutral | Grau | — |

**Light Mode**

| Element | Farbe |
|---|---|
| Content-Hintergrund | `#FFFFFF` |
| Sidebar / Karten-Hintergrund | `#F5F5F5` |
| Haupttext | `#111827` |
| Sekundärtext | Mittleres Grau |

**Dark Mode**

| Element | Farbe |
|---|---|
| Content-Hintergrund | `#111827` |
| Sidebar-Hintergrund | `#0D1117` |
| Karten-Hintergrund | `#1F2937` |
| Haupttext | `#F9FAFB` |
| Sekundärtext | Gedimmtes Grau |

**Prinzip:** Farbe transportiert immer Bedeutung — kein dekoratives Colorblocking. Negativer Cashflow = rot, positiver = grün.

**Dark/Light Switch:** Manuell umschaltbar in den App-Einstellungen.

---

## Typografie & Hierarchie

Systemschrift SF Pro, in Gewicht und Größe gestaffelt. Hierarchie funktioniert ohne Farbe.

| Rolle | Größe | Gewicht | Verwendung |
|---|---|---|---|
| Display | 28pt | Semibold | Kaufpreis, Gesamtinvestment — die eine dominante Zahl |
| Headline | 17pt | Semibold | KPI-Bezeichnungen, Tab-Titel |
| Body | 13pt | Regular | Fließtext, Beschreibungen, Notizen |
| Caption | 11pt | Regular | Benchmark-Hinweise, Datumsangaben |
| Mono | 13pt | Regular | Alle Zahlen (SF Mono) |

**Zahlen immer in SF Mono:** Sorgt dafür dass Dezimalstellen untereinander ausgerichtet sind — wichtig für Tilgungspläne und Cashflow-Tabellen.

**Hierarchie in KPI-Karten:**
```
Bruttorendite          ← Caption, grau
4,1 %                  ← Display, fast schwarz
Gut für diese Lage     ← Caption, grau, italic
```

---

## Spacing & Layout

- **Grid:** 12pt Basiseinheit
- Innenabstand in Karten: 12pt
- Abstand zwischen Karten: 12pt
- Seitenränder Content-Bereich: 24pt

---

## KPI-Karten

- Kein Border
- Leichter Schatten (`shadow radius 4, opacity 0.08`) — setzt Karte vom Hintergrund ab ohne schwer zu wirken
- Abgerundete Ecken (`cornerRadius 10`)
- Hintergrund: Kartenfarbe (Light `#F5F5F5`, Dark `#1F2937`)

---

## Icons

SF Symbols — keine eigenen Icons. Konsistent mit macOS, kein Wartungsaufwand.

---

## Navigation

Schmale Sidebar links für Hauptnavigation, breiter Content-Bereich rechts.

```
┌─────────┬──────────────────────────────────────────┐
│ 🏠      │  Portfolio                               │
│ 📊      │  ┌─ Aggregierte KPIs ─────────────────┐ │
│ ⚙️      │  │  LTV 68%  Rendite 4,1%  CF −87€    │ │
│         │  └────────────────────────────────────┘ │
│         │                                          │
│         │  ┌──────────┐  ┌──────────┐             │
│         │  │ ETW      │  │ MFH      │             │
│         │  │ Dresden  │  │ Berlin   │             │
│         │  └──────────┘  └──────────┘             │
└─────────┴──────────────────────────────────────────┘
```

**Sidebar-Einträge:** Portfolio · Investment-Rechner · Einstellungen

**Portfolio-Sektion:**
- Oben: Aggregierte Portfolio-KPIs (Gesamt-LTV, Portfolio-Rendite, Gesamt-Cashflow)
- Darunter: Immobilien als Karten-Grid
- Klick auf Karte → Immobilien-Detailansicht (voller Content-Bereich)

**Immobilien-Detailansicht:**
```
Tab-Leiste: Übersicht | Cashflow | Steuer | Finanzierung | Einstellungen
```

---

## Wizard (Immobilie anlegen)

Progress-Bar oben zeigt aktuellen Schritt — kein separates Navigations-Panel.

```
●────●────○────○────○────○────○
Stammdaten  Objekt  Kauf ...
```

---

## Tabellen & Visualisierungen

- Zeilentrennung: Zebra-Stripes (abwechselnde Zeilenfärbung)
- Zahlenkolumnen rechtsbündig, SF Mono
- Tabellen werden wo möglich durch Visualisierungen ergänzt (Swift Charts):
  - Tilgungsplan → LTV-Kurve als Liniendiagramm
  - Cashflow-Verlauf → Balkendiagramm Soll vs. Ist
  - Portfolio-Verteilung → einfaches Donut-/Balkendiagramm

---

## Animationen & Übergänge

Subtile Übergänge beim Navigieren — sanftes Einblenden beim Wechsel zwischen Sektionen und beim Öffnen einer Immobilie. Keine übertriebenen Animationen, Dauer max. 200ms.
